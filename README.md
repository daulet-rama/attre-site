# attré — прототип каталога

Статический сайт-каталог на трёх языках (рус / қаз / eng) для показа заказчику.
Сейчас живёт на GitHub Pages, позже переезжает на Next.js + Payload и хостинг в Казахстане.

**Прототип:** фото — Unsplash (Unsplash License), названия и цены условные, сайт закрыт от поисковиков (`PROTOTYPE = True` в `build.py`).

## Как устроено

```
data/i18n.json       тексты интерфейса, категории, материалы — на трёх языках
data/products.json   товары: названия/цвет/описание на трёх языках, цена в ₸, остаток, фото
src/css, src/js      стили (mobile-first) и маленький скрипт без фреймворков
src/fonts            onest-var.woff2 — один переменный файл на все веса (45 КБ)
src/img              логотип, иконки, обработанные фото товаров
build.py             сборка data + src → site/ (только стандартная библиотека Python)
tools/               подготовка шрифта и фото (нужны fonttools/brotli и Pillow)
```

Страницы: `/{ru,kz,en}/` каталог, `/{lang}/c/<категория>/`, `/{lang}/p/<товар>/`, `/{lang}/info/`.
У каждого товара своя страница с `og:image`, поэтому ссылка в WhatsApp и Telegram приходит с картинкой.

## Сборка и просмотр

```bash
ATTRE_BASE=/ ATTRE_ORIGIN=http://localhost:8000 python3 build.py && python3 -m http.server 8000 -d site
```

На GitHub Pages сайт собирается сам при пуше в `main` (`.github/workflows/pages.yml`).

## Шрифт

Onest (OFL). `tools/subset_fonts.py` собирает подмножество: латиница, кириллица с казахскими
буквами Ә Ғ Қ Ң Ө Ұ Ү Һ І, знак ₸, №, кавычки и тире. После сборки скрипт проверяет, что эти
символы на месте, и падает, если нет. Символов ● ■ □ в Onest нет — точки и метки рисуются CSS.

## Правила данных

- Проданный товар не удаляется: `stock: 0` → метка «продано», страница и ссылки живут.
- `stock: 1` → метка «последняя».
- Цена — число в тенге, формат «89 000 ₸» собирается автоматически.
- Поля «производитель» и «страна производства» обязательны по закону РК — сейчас «уточняется».

## До боевого запуска

- Реквизиты продавца, часы работы, ссылка на орган по защите прав потребителей (подвал и `/info/`).
- Векторный логотип (SVG) вместо PNG.
- Проверка казахских текстов носителем языка.
- `PROTOTYPE = False`, свой домен, перенос на хостинг в РК.
