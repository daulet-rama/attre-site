# attré — сайт-каталог (прототип)

Минималистичный каталог на трёх языках (рус / қаз / eng). Ориентиры: Massimo Dutti, Ushatava, Antihero —
белое поле, мелкие заглавные подписи, большие фото, только мягкое проявление картинок.
Сейчас живёт на GitHub Pages, позже переезжает на хостинг в Казахстане.

**Прототип:** цены и характеристики уточняются (на сайте «цена по запросу»), сайт закрыт от поисковиков
(`PROTOTYPE = True` в `build.py`). Фото — реальные, из папки заказчика на Google Drive.

## Варианты дизайна

Одни данные и фото — несколько тем вёрстки (`themes/*.py` + `src/css/<тема>.css`):

| адрес | тема | по мотивам |
|---|---|---|
| `/ru/` | gallery — «Галерея» | исходный минималистичный вариант |
| `/v1/ru/` | v1 | yourantihero.ru |
| `/v2/ru/` | v2 | ushatava.ru |
| `/v3/ru/` | v3 | massimodutti.com |
| `/v4/ru/` | v4 — «Витрина» (**выбрана заказчицей**, развиваем её) | Ushatava × Massimo, без анимаций при прокрутке |
| `/v5/ru/` | v5 — «Лента» | Antihero × Instagram: сумка на экран, сетка как профиль |
| `/v6/ru/` | v6 — «Музей» | экспозиция строчными, асимметрия, фото «оседают» |

Список со ссылками: `/variants/`. Быстро пересобрать одну тему без нарезки фото:
`ATTRE_BASE=/ ATTRE_ORIGIN=http://localhost:8000 python3 tools/theme_preview.py v1`.
Остальные темы пока собираются для истории; когда станут не нужны — удаляются из `build.py` (список `THEMES`).
Подкатегории (кардхолдеры, брелоки внутри «аксессуаров») видит только «Витрина» (`NESTED_CATS = True` в теме);
старые темы получают вещи с категорией верхнего уровня.

### «Витрина» (v4)

- Полоса «дарим 2 000 ₸ на первый заказ» — чёрная; `?bar=red` в адресе делает её красной до конца сессии
  (`?bar=black` — обратно), чтобы заказчица сравнила.
- Главная: слайдер из 5 фото с кнопкой «каталог» (`home.json` → `hero`), «новинки» и «популярное»
  (флаги `new`, `popular` у вещи), видео «за кадром» (`home.json` → `video`, файл уже сжат: H.264, 4:5),
  «нас носят» (`home.json` → `wear`), магазин.
- Каталог: категории строкой, фильтр в нижнем листе — сортировка, материал, цвет, цена (бегунок 12 450–98 000 ₸,
  включается, когда у вещей появятся цены). Фильтр пишется в адрес: `catalog/?mat=suede&col=red`.
- Товар: фото листаются вправо-влево; `soon: true` → «скоро в наличии» и кнопка «узнать о поступлении».
- Избранное — в localStorage браузера (переживает перезагрузку, но не переходит на другое устройство
  или из Instagram в Safari); страница `/fav/` отправляет список в WhatsApp. Страница «о бренде» — `/about/`.
- Корзина — тоже в localStorage (ключ `attre-cart`, позиции `{slug, qty}`). На странице товара кнопка «в корзину»
  (у проданных и «скоро в наличии» её нет), после нажатия — «перейти в корзину»; в шапке сумка со счётчиком.
  Страница `/cart/`: количество 1–5 (у штучной вещи — не больше остатка), «удалить», итог — сумма в ₸, если цена есть
  у всех вещей, иначе «цена по запросу», и напоминание о бонусе 2 000 ₸. «Оформить в WhatsApp» открывает чат с готовым
  текстом: позиции (название, №, количество, ссылка), итог и строка про бонус на первый заказ. Сервера и полей
  с личными данными нет — сообщение человек отправляет сам: данные покупателей по закону РК нельзя хранить вне
  Казахстана, поэтому заявка в Telegram появится позже, на сервере в РК. Вещь, проданная, пока лежала в корзине,
  остаётся в списке с пометкой «не войдёт в заказ». Без JS корзины нет: на товаре остаётся кнопка WhatsApp с подписью.

## Как устроено

```
data/products/*.json    одна вещь = один файл; имя файла = адрес страницы /{lang}/p/<имя>/
data/categories/*.json  категории (ключ, порядок, названия на 3 языках; `parent` — у подкатегории)
data/materials/*.json   материалы фильтра: кожа, замша, ворс, текстиль, эко-кожа
data/colors.json        палитра фильтра: 12 цветов заказчицы (ключ, образец, названия)
data/settings.json      WhatsApp, Instagram, почта, ссылка на карту
data/home.json          фото главной: слайдер, видео, «нас носят», «о бренде»; обложка и баннеры — для старых тем
data/i18n.json          тексты интерфейса на трёх языках (слоган — ключи slogan_1/slogan_2)
media/products/         мастер-копии фото вещей (JPEG до 2200px, q92)
media/home/             мастер-копии фото главной
src/                    стили, скрипт, шрифт, логотипы
core.py                 данные, нарезка фото, общие помощники
themes/                 темы вёрстки (gallery, v1–v6)
build.py                сборка всех тем → site/ (Python 3.12+ и Pillow)
tools/                  подготовка шрифта и брендовых картинок
```

Фото для сайта режутся при сборке из мастер-копий: кадр 3:4, 600 и 1200px, WebP q86 — сжатие один раз.
Предметная съёмка на однотонном фоне не обрезается: фон продлевается, вещь остаётся целиком.
У каждой вещи своя страница с картинкой для превью ссылки в WhatsApp и Telegram.

## Сборка и просмотр

```bash
ATTRE_BASE=/ ATTRE_ORIGIN=http://localhost:8000 python3 build.py && python3 -m http.server 8000 -d site
```

На GitHub Pages сайт собирается сам при пуше в `main` (`.github/workflows/pages.yml`).

## Правила данных

- Нет цены → «цена по запросу». Нет остатка → вещь просто в наличии; `stock: 0` → «продано»
  (страница не удаляется, старые ссылки живут); `stock: 1` → «осталась 1».
- Поля «производитель» и «страна производства» обязательны по закону РК — сейчас «уточняется».
- Ошибка в файле вещи не роняет сборку: вещь пропускается, причина печатается как «ВНИМАНИЕ».
- `materials` и `colors` — списки ключей из `data/materials/` и `data/colors.json` (по ним работает фильтр).
  Сейчас это черновик по фото: у моделей с разными расцветками бывает несколько материалов.
- `new`, `popular`, `soon` — черновик для показа (новинки = модели с новых фото).

## Иконка сайта

«a´» — буква «a» и штрих из логотипа, чёрно-белая (просьба заказчицы, как «m´» у muliér):
`src/img/brand/favicon.svg` (в тёмной теме браузера — белая), `favicon.png` 64px и `apple-touch-icon.png` 180px —
чёрное на белом для Safari и iPhone. Собрана из контуров `logo-black.svg`; `tools/brand_assets.py` её больше не рисует.

## Шрифт

Onest (OFL), один переменный файл с латиницей, кириллицей, казахскими буквами Ә Ғ Қ Ң Ө Ұ Ү Һ І и знаком ₸.
`tools/subset_fonts.py` пересобирает его и проверяет, что эти символы на месте.

## Слоган

«not mass. not repeated.» берётся из `data/i18n.json` (ключи `slogan_1`, `slogan_2`). Если владелица решит
локализовать — варианты от копирайтеров и судей-носителей:

| | часть 1 | часть 2 | оценка |
|---|---|---|---|
| рус | не на каждом углу. | не повторится. | 8/10 |
| рус | не массовка. | дубля не будет. | 7/10 |
| қаз | көптің бірі емес. | қайталанбас. | 9/10 |

После смены слогана: `python tools/brand_assets.py` (превью ссылки og-{ru,kz,en}.jpg).

## До боевого запуска

- Цены, размеры, производитель и страна по каждой модели; проверить черновик материалов и цветов.
- Условия бонуса 2 000 ₸ (минимальная сумма, срок, сочетание с акциями).
- Реквизиты продавца, ссылка на орган по защите прав потребителей (часы работы: 11:00–20:00 — уже на сайте).
- Логотип: сейчас SVG — обводка PNG заказчицы (`tools/logo_svg.py`); если у неё есть исходник в векторе — заменить.
  Проверка казахских текстов носителем языка.
- `PROTOTYPE = False`, свой домен, перенос на хостинг в РК.
